# Contributing

Thanks for your interest in improving this portfolio lab.

## How to contribute

1. Open an issue describing the detection use case.
2. Fork and create a feature branch.
3. Add or update:
   - detection metadata in `detections/`
   - Sigma rule in `sigma-rules/`
   - sample logs in `logs/`
   - validation/tests if needed
4. Run `make test` before opening a PR.

## Contribution standards

- Keep content portfolio-focused and educational.
- Add ATT&CK mappings where possible.
- Document false positives and triage steps.
- Do not claim production SOC incidents or employer data.
